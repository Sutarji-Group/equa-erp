# Operator depot (POS) — panduan 1 halaman

Aplikasi **/pos** di tablet depot. Tetap bekerja **tanpa sinyal**; data terkirim sendiri saat sinyal kembali.

**Masuk.** Pilih nama → PIN. Bergantian: **Ganti operator** (data tetap tersimpan).

**1. Buka shift.** Hitung uang di laci (kas awal tetap tampil; beda → keterangan) → periksa stok awal → **Buka shift**.

**2. Jual (≤ 3 langkah).** Ketuk produk → atur **+/−** → **Tunai** (isi uang diterima / **Uang pas**) atau **QRIS**
(periksa dana masuk) → **Simpan**. Harga dari kantor, tidak diketik. Tanpa sinyal nomor struk sementara; nomor resmi
terbit saat terkirim.

**3. Salah transaksi.** **Shift & void** → transaksi → **Void…** → alasan. Nilai besar menunggu persetujuan pemilik
(transaksi tetap dihitung). Pembeli tetap membeli → **Buat transaksi pengganti**.

**4. Kas terlalu banyak.** Muncul peringatan → **Setor sebagian** + foto slip setor bank.

**5. Pasokan air datang.** **Pasokan air** → truk **Tiba** → **Sesuai, terima**, atau **Volume berbeda** (isi volume &
alasan).

**6. Bahan (tutup, tisu, galon).** **Stok bahan**: terima transfer dari toko / bahan pemasok lain (foto nota). **Opname
mingguan** paling lambat Minggu: hitung fisik → alasan bila beda → **Kirim opname**.

**7. Tutup shift.** **Shift & void → Tutup shift** → hitung uang, isi **Kas fisik** & **stok fisik** (beda → alasan) →
**Tutup shift** (boleh tanpa sinyal).

**8. Setor.** **Riwayat → Setoran shift terakhir** → **Serah fisik** atau **Setor bank (foto slip)** → **Tandai sudah
disetor**. Hasil (Diterima, selisih) tampil di kartu **Setoran & ganti rugi saya**.

**Status data.** *Tersimpan di ponsel: N* = belum terkirim — lanjut kerja. Jangan hapus data peramban sebelum
**Semua terkirim**. Data ditolak server tampil di **Antrean data** beserta alasannya.

**PIN:** salah 5× = terkunci 15 menit; lupa → minta admin sistem mereset. **Kendala aplikasi:** menu **Bantuan**.
