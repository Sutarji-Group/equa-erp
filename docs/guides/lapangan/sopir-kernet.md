# Sopir & kernet — panduan 1 halaman

Aplikasi **/sopir** di ponsel truk. Tetap bekerja **tanpa sinyal**; data terkirim sendiri saat sinyal kembali.

**Masuk.** Pilih nama → PIN 6 angka (PIN milik Anda, jangan dipinjamkan). Salah 5× = terkunci 15 menit. Ganti orang:
**Ganti pengguna**.

**Satu rit = 3 tombol.**
1. **Berangkat** saat truk jalan.
2. **Tiba** di lokasi pelanggan.
3. **Selesai & bayar**: foto bukti kirim (wajib) + nama & tanda tangan penerima + volume → pembayaran (**Tunai**: isi uang
   yang diterima; **Transfer**: foto bukti; **Tempo**: hanya bila diizinkan — minta lewat **Pelanggan minta tempo?**) →
   **Simpan** → **Kirim struk WA**.

Harga tidak diketik — hanya harga pesanan yang berlaku. Rit bertanda **SUDAH DIBAYAR** tidak ditagih lagi.

**Tidak jadi kirim?** Rit → **Rit gagal** → alasan + foto + air dibawa/kembali/dibongkar. **Truk rusak/jalan ditutup** →
**Kendala**.

**Pelunasan piutang.** Rincian rit → **Terima pelunasan** → centang faktur → tunai/transfer → simpan → kirim bukti WA.

**BBM, tol, parkir.** **Setor → Catat pengeluaran** → jumlah + **foto nota**.

**Keterangan perjalanan.** Muncul tugas di menu **Keterangan** (berhenti lama, di luar jadwal) → isi hari itu juga.
Jangan mencabut GPS truk; biarkan lokasi ponsel menyala.

**Akhir hari: Setor.** Semua rit Selesai/Gagal → **Setor Rp …** → serahkan uang ke Admin Keuangan. Hasil & selisih
tampil di kartu **Setoran & ganti rugi saya**. Tombol **Berangkat** terkunci besok bila setoran belum ditutup kantor.

**Status data.** *Tersimpan di ponsel: N* = belum terkirim (tidak apa-apa, lanjut kerja). Jangan hapus aplikasi/data
peramban sebelum **Semua terkirim**. Muncul **Perbarui aplikasi** → muat ulang dulu. **Data dari kantor** (rit baru, faktur, keputusan) masuk sendiri: segera setelah data Anda terkirim, saat aplikasi dibuka lagi, dan tiap
±5 menit selama aplikasi terbuka. Perlu segera → ketuk pil status (**kirim sekarang**).
Foto diperkecil otomatis (±150 KB) agar hemat kuota.

**Kernet:** hanya melihat rit, kecuali ditetapkan Dispatcher sebagai pengemudi pengganti hari itu.

**Ponsel hilang/rusak:** segera telepon Admin Keuangan/Dispatcher. **Kendala aplikasi:** **Bantuan → Laporkan kendala**.
