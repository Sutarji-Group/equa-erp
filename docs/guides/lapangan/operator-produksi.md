# Operator produksi (sumber air) — panduan 1 halaman

Aplikasi **/produksi** di ponsel sumber air. Tetap bekerja **tanpa sinyal**. Anda hanya memasukkan kenyataan (angka
meter, volume, alasan); produksi, susut, dan utilisasi dihitung sistem.

**Masuk.** Pilih nama → PIN 6 angka. Layar **Hari ini**: meter pagi/malam, pengisian, tugas.

**Catat meter (pagi & malam, 3 langkah).** **Catat meter** →
1. meter pagi/malam sudah dipilihkan;
2. ketik angka meter (liter) — lebih kecil dari sebelumnya ditolak, periksa lagi;
3. **foto meter (wajib)** → simpan. Lewat 08.00 (pagi) / 23.00 (malam) → tulis alasan terlambat.

Salah angka tidak bisa diubah dari ponsel → lapor Admin Keuangan (koreksi berfoto). Meter berputar ke nol/diganti →
hubungi Admin Keuangan dulu.

**Isi truk (3 langkah).** **Isi truk** →
1. pilih truk (yang dijadwalkan paling atas; truk lain → **Truk lain…** + konfirmasi);
2. volume (bawaan 5.000 L; beda → alasan, mis. **Sisa muatan**) & rit tujuan (tidak ada → **Tanpa rit**);
3. simpan (foto boleh).

**Susut di atas batas.** Kotak merah **Isi penjelasan susut** → pilih alasan + **foto** → kirim. Pemilik menerima atau
mengembalikan dengan catatan.

**Lainnya.** **Level tandon** (opsional) · **Hasil uji mutu** (lab, nilai, foto sertifikat; tidak lulus → tindakan,
penanggung jawab, tenggat) · **Riwayat**.

**Status data.** *Tersimpan di ponsel* → *Terkirim* sendiri saat sinyal kembali (**Semua terkirim**). Jangan hapus
aplikasi/data peramban sebelum semua terkirim. Muncul **Perbarui aplikasi** → muat ulang dulu. **Data dari kantor** (jadwal isi truk, keputusan) masuk sendiri: segera setelah data Anda terkirim, saat aplikasi dibuka lagi, dan tiap
±5 menit selama aplikasi terbuka. Perlu segera → ketuk pil status (**kirim sekarang**).

**PIN:** salah 5× = terkunci 15 menit; lupa → minta admin sistem. **Kendala aplikasi:** **Bantuan → Laporkan kendala**
(ada juga **Kirim sekarang**).
