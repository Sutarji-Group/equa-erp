# Kasir toko (POS) — panduan 1 halaman

Aplikasi **/pos** di tablet toko (mode toko otomatis). Tetap bekerja **tanpa sinyal**. Kasir hanya memakai POS.

**Masuk.** Pilih nama → PIN. Menu: **Jual · Shift & kas · Terima barang · Stok & opname · Usulan · Riwayat**.

**1. Buka shift.** Hitung uang di laci → beda → keterangan → **Buka shift**.

**2. Jual (≤ 3 langkah).** Pilih **Pelanggan** (*Umum* = harga umum; **mitra toko** = harga mitra otomatis) → cari/**Pindai**
barang, atur **+/−** → **Tunai** / **QRIS** / **Tempo mitra** → struk **Cetak/PDF** atau **Kirim WA**.
- Diskon di atas batas → menunggu pemilik; **jangan serahkan barang** sebelum disetujui.
- Tempo melewati batas/Ditahan → tunai/QRIS atau **Ajukan persetujuan pemilik**.

**3. Salah transaksi hari ini.** **Shift & kas** → transaksi → **Void…** (alasan). Retur setelah shift ditutup dicatat
kantor.

**4. Terima barang.** **Terima barang** → pemasok, nomor & tanggal nota, **foto nota**, barang + jumlah + harga beli,
**Total di nota** harus sama → **Simpan penerimaan**. Nota hilang → **Nota pengganti** (menunggu Admin Keuangan).

**5. Stok.** **Pesan ulang**: barang ≤ stok minimum → **Sudah dipesan**. **Opname** bulanan bersama Admin Keuangan:
hitung fisik apa adanya → alasan bila beda. **Transfer ke depot**: tutup/tisu/galon kosong → **Kirim ke depot**.

**6. Usulan.** Barang baru, harga jual baru, pemasok baru → **Kirim usulan** (berlaku setelah disetujui).

**7. Tutup shift & setor.** **Shift & kas → Tutup shift** → isi **Kas fisik** (QRIS & tempo tidak di laci) → beda →
alasan → **Tutup shift** → **Riwayat → Setoran shift terakhir → Tandai sudah disetor**. Kas kantor tidak dapat ditutup
sebelum shift toko ditutup.

**Status data.** *Tersimpan di ponsel: N* = belum terkirim — lanjut kerja; jangan hapus data peramban sebelum
**Semua terkirim**. **Kendala aplikasi:** menu **Bantuan**.
